# 按需展示搜索热度趋势

用于“看看搜索热度走势”“展开近30天曲线”“这个主题最近是在升温吗”等请求。普通资讯报告保留热度和来源摘要，不为每条自动展开图表。采集、尺度与评分继续遵循[关注度与排序](news-ranking.md)；此能力不要求安装新的研究依赖。

## 数据先于展示

- 优先使用本次已核验的真实序列，或按正常来源访问方式取得数据。先读取用户指定窗口；未指定时可从近30个已完成自然日开始，标明实际日期、地域和时区。
- 保存查询词或Topic ID、词/主题类型、来源链接、类别、搜索类型、采集时间、分辨率和比较批次。核对时间点对齐，识别缺失、低量及未完成周期；真实观测标`data_kind: observed`。
- 一次明确的限流或权限失败后，不连续刷新同一来源。可使用已有合法导出或其他可核对的真实来源；口径改变要明确说明。更早的真实序列只有在标清原日期时才可展示，不能冒充本期。
- 没有真实序列时，显示“暂无可用真实趋势”，列明查询条件、来源状态、尝试时间和原始查询链接。限流可说明HTTP429；无权限、低量或访问失败分别说明。保留未知，不画零线、不延续旧值、不插值补出走势，也不生成模拟曲线。
- 用户明确要求“只看形式样例”“用模拟数据演示”时，才制作演示。仅要求看趋势、或说“随便挑一个主题”，不构成使用模拟数据的授权。

无数据时的简短交付可以是：

```text
ChatGPT · 近30天搜索热度
暂无可用真实趋势：Google Trends 本次限流（HTTP429）。
查询条件：全球 / 网页搜索 / 明确起止日期与时区。
附可核对的查询链接；本次没有曲线，也没有搜索热度评分。
```

## 展示结构

让读者能看见走势、核对数值和理解口径，采用已确认的展示形式：

1. **标题与知识位置**：主题名称及所属节点。广义品牌趋势注明仅是品牌背景，不归因到某一新闻事件。
2. **查询摘要**：实际时间窗、地域、搜索类型与真实数据来源。来源不是Google时使用其实际名称和指标单位。
3. **少量摘要**：最近一个完整周期的指数、最近7个完整日的均值、相较前7日均值的变化；只显示有充分数据支持的项。
4. **主曲线**：日期横轴、明确单位的纵轴。Google网页指数固定0—100；其他来源按自己的尺度展示，不能强制转成Google指数。
5. **可选交互**：查看逐点日期和数值、显示/隐藏7日均线、切换7天/30天可见区间。只裁切同一已取得序列，维持原比较窗口与归一化尺度；不把重新查询的数据悄悄替换进来。
6. **口径详情**：可展开查看实际查询、词/主题口径、来源链接、采集时间、分辨率、比较批次和缺失/部分数据说明。正文不必反复堆放这些细节。

有可用的可视化技能或宿主图表工具时，按其规范生成交互预览。没有交互能力时用可用的静态折线图，并保留时间、单位、来源和数据状态；不把“支持悬停或切换”写成已经实现。无需为了展示安装整套应用或发布站点。

## 计算与解释

- 7日均线使用当日与前6个连续、完整且有观测的自然日；不足7点或期间缺失则该处为空，不用更早数据凑足，也不按点数假定一定是日数据。小时或周粒度需先明确采用的日聚合方法，或省略日均线。
- “较前7天”比较两个相邻、不重叠、同尺度的完整7日均值。前期均值为0、样本不完整或窗口不足14日时不算增长百分比，明确显示不可计算。缺失点留空，不能平滑连接成已知走势。
- 切换展示区间不重新定标；摘要若仍指整个已取得窗口，应把统计区间写在标签里。不要让读者误以为筛选后重新计算或归一化。
- 走势反映查询兴趣，不自动说明产品质量、新闻影响或变化原因。新闻事件标注仅在日期和关联有来源支撑时添加，不按峰值猜原因。

## 显式演示与正式数据隔离

用户明确要求模拟演示时，标题旁和口径详情持续显示“模拟数据／仅形式预览”，摘要与曲线也能辨认其演示性质；不能只在回复末尾小字说明。查询链接仅供日后核对，不冒充数值来源。

模拟记录用`data_kind: simulated`，不混入真实序列或正式报告事实，不计算正式搜索兴趣E，也不计入个人掌握证据。排序复算器即使收到模拟记录和`status: ok`也保持E未知。代码测试夹具和文档结构示例可以使用合成数值，但它们不是用户趋势报告。

本次趋势可作为相应知识节点下的可选阅读内容，纪事只保存用户实际要求的成果。若记档，真实曲线保留干净序列与查询口径；不可用记录保留实际失败状态；显式形式演示独立保存并标清性质，不能以同名文件覆盖真实历史。
